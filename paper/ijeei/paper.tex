% --- Abstract ---------------------------------------------------------------
\begin{abstract}
The Command Query Responsibility Segregation (CQRS) architecture is widely used in distributed systems to separate read and write paths, but it requires asynchronous synchronization through a message broker and exposes the system to eventual consistency. Two parameters dominate this synchronization: batch size and poll interval. Static settings cannot track varying workloads, and prior dynamic-batching approaches rely on heuristics that consider only one metric at a time. This paper formulates the synchronization pipeline as a discrete-time linear MIMO system and applies a Linear Quadratic Regulator (LQR) whose cost function explicitly trades off backlog reduction, latency, and resource utilization. The state-space model is identified from open-loop measurements, and the controller is compared against static, rule-based, and PID baselines on five load patterns and three weighting configurations. Across these conditions, the LQR controller achieves the lowest mean and max normalized regret, indicating both optimality on average and robustness to changes in the priority configuration.
\end{abstract}
